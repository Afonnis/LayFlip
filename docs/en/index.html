Fixes text typed in the wrong keyboard layout

Free for personal use, for Windows. For anyone who switches between keyboard layouts: "Ghbdtn, rfr ltkf?" becomes "Привет, как дела?", "руддщ цщкдв" becomes "hello world". 38 languages, from Russian, Ukrainian and Kazakh to German, French, Greek, Hebrew, Arabic, Armenian and Georgian.

Select it, hold the key under Esc (`) and scroll up. Scroll down to undo.

A short press still types the key as usual — the gesture only reacts to holding it while scrolling.

Why you can trust it

Verifiable

Works on your computer only

Check it yourself: block the program in Windows Firewall or watch its connections in Resource Monitor — there are none, and it works the same. What it reads and stores is spelled out in the privacy notes.

Local

Records nothing, sends nothing

The only network request in the whole program is "Check for updates", which opens the releases page in your browser when you click it. No background checks, no telemetry, no history of what you typed.

Honest

Not code-signed yet

Windows SmartScreen may warn about an unknown publisher — click "More info" → "Run anyway". If Smart App Control blocks the installer: right-click the file → Properties → tick "Unblock" → OK. That is expected for a new unsigned app, not a sign of anything malicious; the installer's checksum is published next to it on the release page.

How it physically works (the hook)

LayFlip installs low-level keyboard and mouse-wheel hooks (WH_KEYBOARD_LL/WH_MOUSE_LL) — the same Windows mechanism layout switchers and clipboard managers use. The hook only looks at which physical key is held and when the wheel turns, to recognise the gesture; it does not read or store the rest of your typing. The text itself reaches the program only at the moment of the gesture, by copying the selection; it is converted in memory and pasted straight back, and your clipboard is restored to what it was before.

Limits (stated plainly)

  • No dictionary. LayFlip does not keep a list of "real words". It uses a statistical letter model (how likely each letter is after the two before it, in each of 38 languages) and looks at the phrase as a whole. That is fast and needs no word lists, but it is occasionally wrong — most often between Russian and Ukrainian, which share nearly every key; then a second scroll switches the whole phrase to the other one.
  • Undo is always at hand. If a fix was wrong, scrolling down (or Ctrl+Z) puts the original back at once, and LayFlip remembers to leave that word alone from then on.
  • A choice, not a guess, for genuinely ambiguous words. When the model cannot pick between two readings with confidence, it does not guess: one more scroll shows the other one.
  • Letters typed with AltGr (Polish ą, Latvian ā, Kyrgyz ң) have no key on a Russian or English layout, so text typed there without them cannot come back in full.

FAQ

How do I fix something?

Select it, hold the key under Esc and scroll the wheel up. Scroll down to undo. A short press types the key as usual, so normal typing is not affected. CapsLock, right Ctrl, right Alt or a mouse side button can be the gesture key instead (Settings).

Which languages does it support?

It converts between the keyboard layouts you have installed in Windows (Settings → Time & language → Language & region). Letter models cover English, Russian, Ukrainian, Belarusian, Bulgarian, Serbian, Macedonian, Tatar, Kazakh, Kyrgyz, Mongolian, Greek, German, French, Spanish, Italian, Portuguese, Polish, Czech, Slovak, Dutch, Swedish, Danish, Norwegian, Finnish, Hungarian, Romanian, Lithuanian, Latvian, Estonian, Icelandic, Croatian, Turkish, Hebrew, Arabic, Persian, Armenian and Georgian.

Does it need administrator rights?

No, it installs for the current user only. The one exception: if the window you paste into runs as administrator, LayFlip has to run as administrator too — Windows does not let a normal app paste into an elevated one. LayFlip shows a notification when that happens.

Can it see what I type?

The low-level hook sees physical key presses and the mouse wheel in order to recognise the gesture, but it does not store or send any text (to fix what you just typed it only counts characters and spaces, in memory). Text reaches the program only at the moment of the gesture, by copying the selected fragment, and is processed locally right away.

Why does it sometimes offer "another reading" instead of a fix?

Russian "ы" and Ukrainian "і" sit on the same key, and for some words the model cannot pick one reading with confidence. Then a second scroll in the same hold shows the alternative instead of silently guessing.
